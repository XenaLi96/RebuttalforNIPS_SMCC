\questionsep
\textbf{Q1.}\quad
\textit{How reliable is Visium HD bin-to-cell aggregation?}

\textbf{A1 (Construction).}
\begin{itemize}
\item Official transforms register native 2-\(\mu\)m bins to H\&E; intersecting
CellViT polygons aggregate counts, conflicts go to the nearest centroid, and
unsupported cells are removed. We will move this rule to the main text and
label HD outputs \emph{derived cell-aligned}, separately from native Xenium.
\end{itemize}

\questionsep
\textbf{Q4.}\quad
\textit{Could in-domain results reflect spatial interpolation?}

\textbf{A.}\enspace We thank the reviewer for raising this important concern.
Random cell splits can be inflated by spatial autocorrelation; ours is
spatially separated.
\begin{itemize}
\item The original in-domain split trains on the left two-thirds and tests on
the right one-third of a section; a 5\% buffer removes boundary cells.
Train/test cells are therefore neither interleaved nor directly neighboring.
The 30-sample benchmark uses four analogous contiguous holdouts.
\item Under identical splits, image macro Gene Pearson is 0.324 versus 0.046
for coordinate-only regression and 0.053 for spatial KNN, and image is
strongest in 28/30 samples. Local interpolation alone therefore cannot explain
the performance.
\end{itemize}

\questionsep
\textbf{Q5.}\quad
\textit{Is the ovarian context analysis too narrow?}

\textbf{A1 (Scope of the ovarian result).}
\begin{itemize}
\item AK (60+) \(\to\) AD (60+) versus AK \(\to\) AL (40-) changes F1
0.289 \(\to\) 0.072 and gene/cell Spearman 0.036/0.206 \(\to\)
0.006/0.095. Because age is nested within sample/patient and panels differ,
this is an \emph{age-associated, sample-confounded shift}, not causal.
\end{itemize}
